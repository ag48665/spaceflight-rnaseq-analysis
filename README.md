# NASA Spaceflight RNA-seq Analysis

## Overview
RNA-seq differential expression analysis of NASA GeneLab spaceflight samples.

## Methods
- PCA
- Differential expression analysis
- Volcano plot
- Heatmap visualization

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- SciPy
- Matplotlib
- Seaborn
- Docker
- Jupyter
