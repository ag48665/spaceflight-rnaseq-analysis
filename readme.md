# NASA GeneLab RNA-seq Analysis

## Overview

This project explores transcriptomic changes in NASA GeneLab RNA-seq data using exploratory bioinformatics workflows.

The analysis includes:
- RNA-seq preprocessing
- Quality control
- PCA visualization
- Differential expression analysis
- Volcano plots
- Heatmaps

## Dataset

NASA GeneLab OSD-401 RNA-seq dataset.

## Workflow

Raw counts → log transformation → PCA → differential expression → visualization
